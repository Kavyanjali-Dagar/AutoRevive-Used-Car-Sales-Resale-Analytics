AutoRevive-Used-Car-Sales-Resale-Analytics

1. Description: 
AutoRevive – Used Car Sales & Resale Analytics is a data analytics project focused on analyzing 7,391 used-car listings to understand pricing, resale trends, market demand, and availability. The project explores how factors such as brand, mileage, fuel type, transmission, car age, ownership, and city affect used-car prices and demand.

2. Tech Stack: 
Python (Pandas) – Data cleaning and preprocessing
MySQL – Data querying and analysis
Microsoft Excel – Data organization and basic analysis
Power BI – Data visualization and dashboard creation.

3. Data Source:
Kaggle – Used Car Price Prediction Dataset by Vrajesh Sharma.

4. Features:
Data Cleaning & Preprocessing – Cleaned missing values, duplicates, and abnormal records using Python (Pandas).
Pricing Analysis – Analyzed average sale prices across brands, fuel types, transmission, and car age.
Market Analysis – Compared car listings across different brands and cities.
Resale Analysis – Compared original prices with sale prices to understand price differences.
Demand Analysis – Analyzed listing views and hot listings to understand customer interest.
Ownership Analysis – Studied how the number of previous owners relates to car prices.
Availability Analysis – Examined the availability status of used-car listings.
Interactive Dashboards – Created two Power BI dashboards for market, pricing, and demand insights.

Highlights:
Analyzed 7,391 used-car listings after data cleaning.
Identified pricing patterns across brands, fuel types, cities, mileage, car age, and ownership.
Created 2 Power BI dashboards: Market Overview and Pricing & Demand Analysis.
Used SQL to perform business-focused analysis and Pandas for initial data preparation.
